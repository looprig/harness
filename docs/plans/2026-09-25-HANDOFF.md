## Decisions already made (do not re-ask)

- `principal` is its own typed Core field (`Principal{Tenant, Subject, Kind}`), optional at the
  wire and in harness, stamped only by Factory when `WithPrincipalStamping()` is on, mandatory
  on every command then, and refused if a client sends it. Stamped on all five command kinds;
  metadata on create and input only.
- Capability token `hostlink.attribution.principal`.
- Presenter prepends/appends text only, runs once, journaled; failure → `refused`.
- Rollback below harness v0.41.0 after stamped records exist is **lossy and forbidden**
  (documented; `v` stays 1).
- Incapable-owner refusal is 422 `runtime_unavailable`.
- `/v1/capabilities` `command_principal` = this Factory stamps; `message_metadata` always true.
- Only explicit `hustle.WithTimeout(0)` means no deadline.
