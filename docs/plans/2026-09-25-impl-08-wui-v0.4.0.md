> v0.12.0 `metadata.go` before Task 4. The harness event shapes (Precondition 3) are

> `input {principal, metadata, prefix, suffix}`; `TurnInterrupted` and `GateResolved` gain

**Goal:** Move wui to core v0.12.0, mirror the new Core request schemas, let the
Factory command plane send optional `metadata` on create/input (never `principal`),
and render what the new journal carries: the presenter frame dimmed around the
user's own blocks, a "from" chip for the stamped sender, and the sender on an
interrupt and on an answered gate. Journals with no `input` render exactly as in
v0.3.0. Ship a reproducible committed bundle as wui v0.4.0.

**Architecture:** Three layers, each with its own tests.

- **Contract.** `make contract` re-vendors Core v0.12.0. `schema.ts` gains
  `factory*` mirrors of the five request schemas and `principal`, generated
  mechanically from the vendored bytes.
- **`@looprig/protocol`.**
  - `commands.ts` builds `metadata` onto create/input after a client-side
    pre-check that mirrors Core's limits.
  - `enduring.ts` decodes `input` and `principal`.
  - `fold.ts` splits a user message into `frame.prefix`, `blocks` and
    `frame.suffix` and carries `principal`.
- **`app`.** `UserBubble` renders the frame dimmed with a "from" chip. The
  tombstone names who interrupted. The Factory detail page shows a "from" chip on
  any event body that carries a principal.

Metadata never reaches the renderer. The public journal strips it (design §4);
wui neither decodes nor displays `input.metadata`.

**Tech stack:** Go 1.26.8 (only the contract drift guard and the embed), TypeScript,
React, Vite, vitest (node mode for protocol, browser mode for react/app), ajv, and
`json-schema-to-ts` (type-only).

**Binding design:** `harness/docs/plans/2026-09-25-message-principal-metadata-presenter-design.md`
§1.1 (wire shapes and limits), §3 (old readers), §4 (visibility) and §6 step 5.
Master plan: `2026-09-25-impl-00-master-plan.md` (row 08).

rule the design names ("canonical encoding of the whole object").

`MessageMetadata.Validate` (`sessionwire/v1/metadata.go`). If Core counts raw bytes
instead, change `canonicalMetadataBytes` below to count the plain `JSON.stringify`

export type MessageMetadata = Readonly<Record<string, string>>;

export type MessageMetadataErrorCode =
  | "too_many_fields"
  | "invalid_key"
  | "reserved_key"
  | "value_too_large"
  | "invalid_value"
  | "too_large";

/** Core's limits (core v0.12.0 metadata.go). Core's decoder at Factory remains the authority. */
export const MAX_METADATA_FIELDS = 16;
export const MAX_METADATA_KEY_BYTES = 64;
export const MAX_METADATA_VALUE_BYTES = 1024;
export const MAX_METADATA_BYTES = 4096;
const METADATA_KEY = /^[a-z][a-z0-9_]{0,63}$/;
const RESERVED_METADATA_PREFIX = "looprig";

export class MessageMetadataError extends TypeError {
  readonly code: MessageMetadataErrorCode;
  readonly key: string;

  constructor(code: MessageMetadataErrorCode, key = "") {
    super(key === "" ? `metadata is invalid (${code})` : `metadata field ${JSON.stringify(key)} is invalid (${code})`);
    this.name = "MessageMetadataError";
    this.code = code;
    this.key = key;

function validMetadataValue(value: string): boolean {
  if (!hasOnlyPairedSurrogates(value)) return false;
  for (let index = 0; index < value.length; index += 1) {
    const unit = value.charCodeAt(index);
    // No U+0000, and no C0 control other than \t and \n.
    if (unit < 0x20 && unit !== 0x09 && unit !== 0x0a) return false;
  }
  return true;
}

/**
 * The byte length of Go's encoding/json encoding of `value` as a JSON string:
 * `<`, `>` and `&` become \u003c/\u003e/\u0026, U+2028/U+2029 are escaped, `"`
 * and `\` are backslash-escaped, and \t and \n take their short forms. Every
 * other character is its UTF-8 bytes. Core measures MaxMetadataBytes over that
 * canonical encoding, and Go sorts map keys, so this is exact.
 */
function goJSONStringBytes(value: string): number {
  let bytes = 2;
  for (const char of value) {
    switch (char) {
      case "<": case ">": case "&": case "\u2028": case "\u2029":
        bytes += 6;
        break;
      case "\"": case "\\": case "\t": case "\n":
        bytes += 2;
        break;
      default:
        bytes += idEncoder.encode(char).byteLength;
    }
  }
  return bytes;
}

function canonicalMetadataBytes(entries: readonly (readonly [string, string])[]): number {
  // {"k":"v",...}: braces, one colon per entry, commas between entries.
  let bytes = 2 + Math.max(entries.length - 1, 0);
  for (const [key, value] of entries) bytes += goJSONStringBytes(key) + 1 + goJSONStringBytes(value);
  return bytes;
}

/** Validates like Core; returns a fresh sorted-key copy, or undefined for absent/empty metadata. */
function metadata(value: MessageMetadata | undefined): MessageMetadata | undefined {
  if (value === undefined) return undefined;
  if (typeof value !== "object" || value === null || Array.isArray(value)) {
    throw new MessageMetadataError("invalid_value");
  }
  const entries = Object.entries(value);
  if (entries.length === 0) return undefined;
  if (entries.length > MAX_METADATA_FIELDS) throw new MessageMetadataError("too_many_fields");
  // Core checks keys in sorted order, and per key: grammar, reserved prefix,
  // value length, value content (core v0.12.0 MessageMetadata.Validate). Mirror
  // both orders so the reported code and key match Core's for any input.
  entries.sort(([a], [b]) => (a < b ? -1 : a > b ? 1 : 0));
  for (const [key, field] of entries) {
    if (!METADATA_KEY.test(key)) throw new MessageMetadataError("invalid_key");
    if (key.startsWith(RESERVED_METADATA_PREFIX)) throw new MessageMetadataError("reserved_key", key);
    if (typeof field !== "string") throw new MessageMetadataError("invalid_value", key);
    if (idEncoder.encode(field).byteLength > MAX_METADATA_VALUE_BYTES) throw new MessageMetadataError("value_too_large", key);
    if (!validMetadataValue(field)) throw new MessageMetadataError("invalid_value", key);
  }
  if (canonicalMetadataBytes(entries) > MAX_METADATA_BYTES) throw new MessageMetadataError("too_large");
  // Insertion order is the caller's; the retained bytes keep the caller's
  // order for readability, and Factory canonicalizes before digesting.
  return Object.fromEntries(Object.entries(value));
}

/**
 * The verified sender Factory stamped on a command (Core sessionwire/v1
 * Principal). Display names are NOT part of it: an app resolves a subject to a
 * name in its own presenter. wui renders the subject.
 */
export interface MessagePrincipal {
  tenant: string;
  subject: string;
  kind: "actor" | "service";
}

/**
 * harness v0.41.0 `event.MessageInput`, as the PUBLIC journal carries it:
 * `metadata` is stripped by harness's public redaction and is deliberately
 * never projected here even if present (audit-only, design §4). `prefix` and
 * `suffix` count the presenter's blocks at the head and tail of the message.
 */
export interface MessageInput {
  principal?: MessagePrincipal;
  prefix: number;
  suffix: number;
}

/** A principal, or undefined when absent or malformed (never guessed). */
export function decodePrincipal(raw: unknown): MessagePrincipal | undefined {
  if (!isRecord(raw)) return undefined;
  const tenant = str(raw["tenant"]);
  const subject = str(raw["subject"]);
  const kind = str(raw["kind"]);
  if (tenant === "" || subject === "" || (kind !== "actor" && kind !== "service")) return undefined;
  return { tenant, subject, kind };
}

function decodeInput(raw: unknown): MessageInput | undefined {
  if (!isRecord(raw)) return undefined;
  const principal = decodePrincipal(raw["principal"]);
  return { ...(principal === undefined ? {} : { principal }), prefix: count(raw["prefix"]), suffix: count(raw["suffix"]) };
}

/** A non-negative safe integer, else 0 (the omitzero absent case included). */
function count(x: unknown): number {
  return typeof x === "number" && Number.isSafeInteger(x) && x >= 0 ? x : 0;
}

/** The stamped sender a public event body names: `input.principal` on a message, `principal` on an interrupt or gate answer. */
export function eventPrincipal(body: unknown): MessagePrincipal | undefined {
  if (!isRecord(body)) return undefined;
  const input = body["input"];
  return decodePrincipal(isRecord(input) ? input["principal"] : undefined) ?? decodePrincipal(body["principal"]);
}

/** What wui shows for a principal: the subject, marked when it is a service. */
export function principalLabel(principal: MessagePrincipal): string {
  return principal.kind === "service" ? `service ${principal.subject}` : principal.subject;
}

```tsx
import { principalLabel, type ContentBlock, type MessagePrincipal, type UserFrame } from "@looprig/protocol";
import { cn } from "../../lib/cn";

// (keep the existing module comment; append:)
// `frame` is the agent presenter's context around the message (harness
// v0.41.0): the model saw it, the user did not type it, so it is dimmed.
// `principal` is the Factory-stamped sender; wui shows the subject, because
// display names are the app presenter's business and never part of identity.

function BlockView({ block, testId, dim }: { block: ContentBlock; testId: string; dim?: boolean }): React.JSX.Element {
  return block.type === "text" ? (
    <span data-testid={testId} className={cn("block", dim && "opacity-60 text-muted")}>{block.text}</span>
  ) : (
    <span
      data-testid={dim ? testId : "user-other-block"}
      className={cn("mt-1 block w-fit rounded bg-bg px-1.5 py-0.5 font-mono text-xs text-muted", dim && "opacity-60")}
    >
      {block.type === "other" ? block.wireType : block.type}
    </span>
  );
}

export function UserBubble({
  blocks,
  pending,
  frame,
  principal,
}: {
  blocks: readonly ContentBlock[];
  pending?: boolean;
  frame?: UserFrame;
  principal?: MessagePrincipal;
}): React.JSX.Element {
  return (
    <div data-testid="user-row" className="flex flex-col items-end px-4 py-2">
      {principal === undefined ? null : (
        <span data-testid="user-from-chip" className="mb-1 rounded-full bg-bg px-2 py-0.5 font-mono text-xs text-muted">
          from {principalLabel(principal)}
        </span>
      )}
      <div
        data-testid="user-bubble"
        data-pending={pending ? "true" : "false"}
        className={cn(
          "max-w-[80%] rounded-2xl bg-accent px-4 py-2 text-sm whitespace-pre-wrap",
          pending && "opacity-60",
        )}
      >
        {frame?.prefix.map((block, index) => <BlockView key={`p${index}`} block={block} testId="user-frame-block" dim />)}
        {blocks.map((block, index) => <BlockView key={index} block={block} testId="user-text" />)}
        {frame?.suffix.map((block, index) => <BlockView key={`s${index}`} block={block} testId="user-frame-block" dim />)}
      </div>
    </div>
  );
}
```
