**Goal:** Host v0.11.0 reads the optional `principal` (all five command kinds) and
`metadata` (create, input) members of a command's stored Core body, strictly and
**before** the dispatch attempt, carries them to the runtime on
`department.RuntimeCommand`, sets `runtimecommand.Admitted.Principal/Metadata` in the
reference harness adapter, and advertises `hostlink.attribution.principal`
unconditionally so a Factory v0.12.0 can gate admission and placement on it.

**Architecture:** One shared block-vs-reject decision (`internal/bodyclass`) is used by
every body reader. `createbody` (create), a new `internal/inputbody` (input), a new
`internal/controlbody` (interrupt, restore) and the existing `internal/gateresponse`
each decode Core's strict request and return the decoded members. The
`DispositionApplier` runs the reader for the command's kind after the claim and
before `BeginAttempt`: a body no Host could ever read is **rejected**, and a body this
Host cannot read but a newer one might (`unknown_field`, `unsupported_version`, a
by-reference body) is **blocked** with nothing written. The decoded members travel on
`RuntimeCommand`. The product `BlockDecoder` still receives the unchanged stored bytes
(input) or the re-presented input-shaped bytes (create), now carrying the members.

**Tech Stack:** Go 1.26.8, `GOWORK=off GOTOOLCHAIN=go1.26.8`; core v0.12.0,
sessionstore v0.14.0, harness v0.41.0 (all from plans 01, 02, 05).

**Design (binding):** `harness/docs/plans/2026-09-25-message-principal-metadata-presenter-design.md`
§1.4, §2, §3, §6 step 4. **Master plan:** `2026-09-25-impl-00-master-plan.md` row 06.

```go
// Package bodyclass holds the ONE decision every reader of a stored command
// body makes before an attempt: is a body this Host cannot read one NO Host
// could ever read (reject it now, while a rejection is still possible), or one
// a NEWER Host may read (leave it claimed, write nothing)?
//
// It is shared rather than restated because the readers must not disagree: a
// create and an input carrying the same unknown member are the same finding,
// and a Host that rejected one and blocked the other would destroy work a
// newer Host in a rolling deployment would have done.
package bodyclass

import (
	"encoding/json"
	"errors"

	sessionwire "github.com/looprig/core/sessionwire/v1"
)

// Members are the optional members a Factory stamps (Principal, every kind)
// or a client supplies (Metadata, create and input). Both zero means the body
// carried neither, which is byte-identical to a pre-feature body.
type Members struct {
	Principal *sessionwire.Principal
	Metadata  sessionwire.MessageMetadata
}

// Permanent reports whether a decode failure is permanent: the immutable bytes
// are malformed under every wire version this Host knows. unknown_field and
// unsupported_version are NOT permanent (a newer Host may read them), and
// neither is a failure Core did not classify, because refusing to guess is the
// safe direction: a block costs time, a rejection destroys the command.
func Permanent(err error) bool {
	var validation *sessionwire.RequestValidationError
	if errors.As(err, &validation) {
		switch validation.Code {
		case sessionwire.RequestValidationCodeInvalidJSON, sessionwire.RequestValidationCodeDuplicateField,
			sessionwire.RequestValidationCodeMissingField, sessionwire.RequestValidationCodeInvalidField:
			return true
		default:
			return false
		}
	}
	var syntax *json.SyntaxError
	var typeError *json.UnmarshalTypeError
	return errors.As(err, &syntax) || errors.As(err, &typeError)
}
```
